    How staff should use this

    1. Pick grade + window (or trust the “we are here” line).
    2. Open the printable packet. Use Day 1, Days 1–2, or all three.
    3. Print to PDF if the office wants a file. No textbook login required.
    4. Collect work when the student returns. Keys, if you add them, stay off the public page.

    Library

    W1 packets for grades 5–8 have full prompts. Other windows print an alignment shell until you copy a block in js/packets.js.
